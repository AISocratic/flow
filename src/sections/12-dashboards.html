12Dashboards

The company's instrument panel — business and machine on one screen.

Every observable thing lands here: audience, growth, revenue-side metrics beside engineering health, error rates, performance, agent throughput, and cost per shipped card. Goals sit next to the metrics that measure them, so "are we winning" and "is the machine healthy" are the same glance. This is also what the monitoring agents read — the dashboard is an API for agents as much as a page for humans.

  • Business — revenue, user growth, campaign open rates.
  • Audience — page views (SEO), traffic, GEO score, SEO score.
  • Product — goals, releases, cards.
  • Agents — agent health, token usage / cost, token budget, errors.
  • Engineering — errors, project health, performance, code quality.
  • Anomalies — charts, alerts.
