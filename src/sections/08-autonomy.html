08Autonomy — automerge vs. review

Trust is a per-card dial, not a global switch.

Every card decides how much freedom its agent gets. Marked automerge, the agent squash-merges its own passing PR and the card lands in Done untouched by human hands. Otherwise the card parks in Review and waits for a verdict: approve, and an agent merges it; request changes, and the feedback goes back to the same agent on the same branch. Low-stakes work flows friction-free; high-stakes work keeps a human gate — on exactly the cards you choose.
