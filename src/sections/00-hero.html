Flow — Agentic Company OS

Goals become projects. Projects become cards. Cards become merged code. Code moves the metrics. Metrics reshape the goals. Flow is an operating loop where a fleet of AI agents does the running — planning, building, verifying, shipping, monitoring — and humans set direction, review where they choose to, or simply observe.

The goal

Run your team or startup in full autonomy:

  1. Install Flow. It integrates with the Kanban board you already have, or builds you one.
  2. Wire up the dashboard so every number lands in one place — engineering, KPIs, traffic, logs, spend.
  3. Give the agents a mission. They decompose it into projects, epics and tasks on the board.
  4. Let the orchestrator run them — epochs of agents working that board until the metric moves.

All of it on your AI subscriptions rather than metered API credits — with an exception for models cheap enough to justify on their own (Gemma 4, DeepSeek, Kimi 3, GLM 5.2) on summarization and other non-mission-critical work.

Human Agent System Data / metrics

Three layers, and Chat — Slack and e-mail, where every human/agent touchpoint happens — sitting above them. Humans set direction into the Plan Layer: mission, quarterly goals and KPIs, the persistent projects under them, and the board those projects decompose into. An agent can also be addressed directly, straight into the Execution Layer, where interchangeable harnesses — Claude Code and Codex on subscription, AI agents on API inference — open PRs that run through verify, merge and deploy into releases. The Monitor Layer is where every number lands: monitoring agents read the dashboard, file new work onto the board, and send insights back to the plan — the return stops there, never at the mission. Underneath it all, the knowledge every agent reads on boot and writes back to after each run.
