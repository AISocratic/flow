14Dashboard

A core component, not a reporting page attached to one.

The dashboard is the single surface where every measurable thing the company produces lands: business results, product usage, engineering health, delivery throughput, cost, and agent performance. Humans read it to decide direction. Agents read it to decide work. Because both audiences share one set of numbers, a goal, the work created to move it, and the evidence that it moved are never held in separate systems.

It is an API as much as a page — the data behind every view is queryable, and most of its readers are not human:

  • Planning agents read KPI gaps, guardrails and historical project impact when proposing projects and epics.
  • The evaluation agent reads outcome metrics when deciding whether a completed epic achieved its intended result.
  • Scheduled jobs and standing agents read thresholds and trends to detect anomalies and file work.
  • The execution-policy router reads agent performance to decide which configuration receives the next card.

The major views are Strategy (mission, quarterly goals and KPIs, projects, epics and the strategic Gantt), Agent performance (the quarterly agent OKRs), plus business and product, engineering and delivery, and anomalies.

One surface, five views, two audiences. Humans read it to decide direction; the planning, evaluation, monitoring and routing agents read the same numbers through the API to decide work. Instrumentation is itself a tracked metric — an outcome nobody measured cannot be evaluated.

Two properties make it trustworthy enough for agents to act on unattended. First, instrumentation is part of the work: a card expected to move a measurable outcome is not complete until the metric that would prove it exists and reports, and missing instrumentation is itself a ticket. Second, attribution is explicit — metric movement is labelled direct, modeled or correlated rather than collapsed into a single causal number. Goals sit beside the metrics that measure them, so "are we winning" and "is the machine healthy" become the same glance.
