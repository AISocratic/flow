14Agent knowledge, memory & self-improvement

What the system learns, it keeps — and uses.

Every agent boots with the system prompt — the constitution: who the company is, what it values, the rules that never change. Beyond that, knowledge lives in five stores:

  • agent.md — per-agent memory. Durable lessons an agent carries between runs — conventions, gotchas, preferences it has learned — plus the steps.md trail of what it did and why.
  • skills.md — shared playbooks. Step-by-step procedures for recurring work (deploys, migrations, review checklists) written once and loadable by any agent on demand; when an agent figures out a better way, the skill is updated for everyone.
  • Code knowledge — the code hierarchy, cached. A script extracts the current hierarchy of the codebase — what lives where, how it connects — and re-runs each time a PR is created, so it never goes stale. Agents read it on boot for a warm start instead of rediscovering the repo cold every run.
  • Company knowledge (RAG) — everything the business knows: docs, decisions, product specs, emails, brand voice. The admin decides what is stored here and how — a Karpathy-style Obsidian second brain, a typical RAG pipeline, or a set of tools that connects the company's services — and any agent retrieves from it at the moment it's needed, so a week-one agent works with years of context.
  • Memory — experimental. After each run the agent distills something worth remembering, and that memory is shared across coding agents — Codex, Claude Code, Open Code, plain API — so a lesson learned on one harness is available to all of them.

Self-improvement is the loop across all five: every run ends by distilling its outcome into the right store, so the next run starts smarter. And because every run is a snapshot (the exact prompt plus the repo commit it ran against), any card can be rolled back and forked: multiple attempts branch from the same snapshot, verification scores pick the winner, and the run tree becomes a search over approaches. The company doesn't just do the work — it gets better at doing the work.
