09Run tracker

Every unit of agent work is a tracked, stateful run.

Runs form a tree in Postgres — orchestrator → epoch → task — and each run moves through an explicit state machine with a heartbeat. A run that stops beating goes stale and can be revived or reaped; a run that hits a question a human must answer pauses in needs-feedback rather than guessing. Nothing an agent does is invisible: every state, timestamp, prompt, and outcome is queryable.
