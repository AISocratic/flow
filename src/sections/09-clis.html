09Two CLIs

Headless hands for agents working in isolated worktrees.

Worktrees don't carry the app's runtime, so all reads and writes go through two small command-line tools. todo-cli is the board: read the plan, update a card, attach a PR, leave a comment. agent-cli is the run lifecycle: start a run, heartbeat, ask a human, finish — plus durable memory reads and writes. Everything an agent does to shared state flows through these two audited doors.
