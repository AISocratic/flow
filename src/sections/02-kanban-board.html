02Kanban board

The single interface between humans and agents.

All work is a card. The hierarchy runs goal → project → epic → task/bug; cards cross-link with dependencies, and every card carries its own execution policy — which model runs it, at what effort, and how much autonomy it gets. Humans and agents use the same board: drag a card, and an agent picks it up; an agent finishes, and the card moves under your cursor. A card that can't proceed right now — blocked on an answer, an external event, or something to revisit later — parks in To follow up instead of clogging the active lanes, then rejoins the flow when it's unblocked.
